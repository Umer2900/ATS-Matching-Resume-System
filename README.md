# 🚀 ATS Matching Resume System

A smart **ATS Matching Resume System** built using Python and Regular Expressions (Regex), deployed with **Streamlit**.  
This project simulates a real-world **Applicant Tracking System (ATS)** by extracting resume data, matching skills with job requirements, calculating ATS scores, and ranking candidates.

---

## 📌 Features

✅ Upload and analyze multiple resumes (PDF & DOCX)  
✅ Extracts:
- Name  
- Email  
- Phone Number  
- Skills  

✅ Skill Matching System  
- Identifies **matched skills**  
- Highlights **missing skills**  

✅ ATS Score Calculation  
- Provides **percentage-based score**  

✅ Candidate Ranking  
- Suggests **Top 5 matching resumes**  

✅ Job Recommendation System  
- Suggests relevant job roles  

✅ Preloaded Dataset  
- Includes **30 dummy CS resumes (ZIP file)** for testing  

✅ Interactive UI  
- Built using **Streamlit** for real-time analysis
